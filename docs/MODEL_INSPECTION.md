# 模型查看、爆炸展示与网格测量

入口：三维模型库。支持已上传的 STEP 预览、GLB、OBJ、STL，也可查看当前参数模型。

## 模型库查找

模型库支持不区分大小写的文件名搜索，可与 GLB、OBJ、STL、STEP/STP 格式筛选组合使用；显示匹配数与总数。支持最新上传、名称和文件大小降序排列，当前打开的资源会高亮。
筛选只改变库列表，不卸载当前模型；上传或生成完成刷新列表时保留当前筛选。刷新页面恢复全部格式及最新上传顺序。没有匹配项时可清空搜索或调整格式。

## 标准方向与局部聚焦

工具栏提供等轴方向和前、后、左、右、顶、底六个方向，基于当前向上轴换算后的显示坐标。当前使用透视投影，不是正交工程图。
“适应可见模型”只计算当前可见网格（包括祖先分组的可见性），隐藏的远处零件不会影响取景。
选中零件或分组后点击“聚焦选中对象”，可快速查看局部；对象完全隐藏时提示先显示对象。
载入新模型会回到等轴方向；切换方向不改变原始文件、零件位置或测量结果。

## 零件搜索

输入零件或分组名称，不区分大小写。搜索会保留匹配项的祖先路径；分组匹配时显示该组后代。
搜索只过滤零件树列表，不改变模型可见性。需要隐藏几何时使用复选框或“隔离选中”。

## 爆炸展示

拖动“爆炸展开”，按各网格的中心相对整体中心径向展开；无明确方向时使用确定性备用方向。
“收拢模型”恢复原始局部位置，不累计位移。改变向上轴或载入另一个模型也会收拢。
这是视觉拆解，不是经过碰撞检测、工具或装配约束验证的真实拆卸路径；单网格模型不能据此恢复原始零件。
原始 STEP、已保存 GLB 和下载文件均不会因展开而改动。

新增 [STEP 实体检查](CAD_INSPECTION.md)：原始 STEP 的 B-rep 最短间距、体积与干涉检查，与下方网格测量分开提供。

## 两点测距

1. 收拢模型，开启“两点测距”。
2. 依次点击可见模型的两个表面点。金色点和线标记本次测量。
3. 结果为这两个点的三维直线距离。拖动旋转仍可使用；点击第三个点开始新测量。
4. 可切换显示为毫米、米或原生单位；“清除测量”移除标记。

单位规则：

- STEP 预览经过单位换算，以米保存，源单位选择锁定；测量默认显示 mm。
- 当前参数模型的源坐标为 mm，源单位选择锁定。
- GLB 按 glTF 约定默认以米解释；非标准文件需人工确认。
- OBJ / STL 默认“未知 / 原生单位”，不会自动推断成 mm。需要确认原始软件的导出单位后，手动选择源网格单位，再换算显示。

结果来自预览三角网格，**不是精确 B-rep 尺寸或最短间距**；没有顶点/边吸附，点击位置会影响结果。
STEP 网格化本身存在近似偏差，不用于制造检验、公差认证或工程签字。
爆炸展开时测距被禁用，以免把展示位移当作真实间距。更换模型、改变向上轴、展开或变更可见性时清除测量。
搜索、爆炸状态、手动单位设置与测量只作用于当前视图，不写回模型文件，刷新后重置。
